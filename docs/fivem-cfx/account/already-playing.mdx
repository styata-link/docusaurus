# Already Playing?

> This likely happens due to a compromised account, or sharing accounts across different computers. If you are sharing your account, please follow the second section.

![](/img/alrpl.png)


If you see this error, the best way to do fix - or resolve these issues are:

1. Change your Social Club password.
2. Enable 2FA on Social Club.
3. Run a deep/full scan with Malwarebytes.
4. Remove mods as they may have been used to steal your account.

> If after a couple days the issue persists then there is currently nothing you can do to remove them from the account.

:::info[Information]
Your only other option would be to purchase GTA on a new account and clear your current identifiers. But you need to make sure whatever caused the issue in the first place is gone.

If that somehow "doesn't" work. Reinstall windows COMPLETELY. Could be an undetected virus/infostealer that takes your accounts.
:::

## I've done this already! Why does this still happen?

Make sure to follow the guide below:

1. Press `Win + R`, enter `%localappdata%\DigitalEntitlements\` and click OK
2. Back up all the files in there, leave them in a separate directory.
3. Delete all the files inside of DigitalEntitlements.
4. Run Grand Theft Auto V once through the relevant launcher you used to install the game with.
5. Your FiveM client should now use your new identifiers, provided you actually have separate licenses.

:::tip
You might also have to delete `%appdata%\CitizenFX\ros_id.dat` which is your Rockstar Social Club identifier.
