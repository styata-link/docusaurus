# Account Bans

## What is a FiveM/RedM Account Ban?

If you received a message that looks like this:

![](/img/gban.png)

It likely means that you have cheated, or the anticheat has found a possible cheat or malware on your computer that directly modified the games files. 
There is no way for you to get unbanned, and all you have to do is wait.

## But I didn't cheat? Why am I still banned?

If you believe you have been false-banned, you can do these steps below:

1. Go to [Rockstar Account Settings](https://socialclub.rockstargames.com/settings), change the password and enable 2-Step verification. If someone else had access to your account, doing this should kick them out.
2. Some client mods may trigger the anti-cheat, if they perform malicious actions. To reinstall FiveM, press the `Windows key + R`, type in `%localappdata%\FiveM` and press OK. Delete all files inside the FiveM folder. Then install a fresh copy from [FiveM's Official Website](https://fivem.net/).
3. It's possible that a virus on your computer is triggering the anti-cheat. Download [Malwarebtyes](https://malwarebytes.com/) and perform a Deep Scan.

> If you have ever installed cheats on your PC, you should perform a factory reset with the "Reset This PC" option and select "Remove everything" to clean up your Windows installation. Make sure to back up any important files.

:::warning[WARNING]
Please note that all bans are final, and they will not be lifted for **ANY** reason.
:::
