# Early Exit Trap

## My game crashes with this crash!

![](/img/eet.png)

Most common fixes for this issue are:

- Upgrading your BIOS
- Remove any cheating software from your system, even if it’s meant for other games
- Remove any mods you may have added to your FiveM client or Grand Theft Auto V installation folders
- Uninstall any recently installed software that might interfere with the game
- Perform an antivirus scan using [Malwarebtyes](https://malwarebytes.com).
