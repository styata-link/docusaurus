# Game Ownership

## I am getting this error when loading up FiveM


![](/img/ownership.png)

## How to fix this crash

You can potentially fix this crash, by doing these steps below:

1. Disable your antivirus
    1. Don't worry, this may be temporary.
2. Allowlisting/Excluding all of Rockstar's folders, including FiveM.
    1. This includes all of Rockstars, Grand Theft Auto and FiveM
3. Re-enabling your Antivirus.

-- OR --

> As always, if you have FiveM on two computers, make sure to do this on both.

!!! Make sure neither FiveM, nor Rockstar Games Launcher is running. !!!
- Press `Win + R`, enter `%localappdata%\DigitalEntitlements\` and click OK
- Back up all the files in there, leave them in a separate directory.
- Delete all the files inside of `DigitalEntitlements`.
- Run Grand Theft Auto V once through the relevant launcher you used to install the game with.
- Your FiveM client should now use your new identifiers, provided you actually have separate licenses.

:::note
If you still have these crashes, try disabling your antivirus - and reload FiveM.
:::
