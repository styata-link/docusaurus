# Legitimacy Crash

> A legitimacy crash could be shown in two separate ways:

1. Crash dialong showing "legitimacy.dll".
2. Crash dialog shown below:

![](/img/ownership.png)

## What could cause these crashes?

There are so many reasons as to why this can happen, but we're going to focus on two of them.

1. Incorrect Identifiers

> This can happen, when you are/not logged in to the wrong Rockstar account. To fix the issue, please do the following:

!!! Make sure neither FiveM, nor Rockstar Games Launcher is running. !!!
- Press `Win + R`, enter `%localappdata%\DigitalEntitlements\` and click OK
- Back up all the files in there, leave them in a separate directory.
- Delete all the files inside of `DigitalEntitlements`.
- Run Grand Theft Auto V once through the relevant launcher you used to install the game with.
- Your FiveM client should now use your new identifiers, provided you actually have separate licenses.

You might also have to delete `%appdata%\CitizenFX\ros_id.dat` which is your Rockstar Social Club identifier.

2. Actually not owning the game.

I mean. Go buy it.

3. Running FiveM/Rockstar launcher as Admin

There are multiple fixes for this, and some of them may not work.

> I have looked through the forums, and seen a few fixes that I have listed below.

- Disable "Run as Administrator" for FiveM, Epic, Steam and Rockstar Launcher.
- Fixing your Date/Time settings on Windows
