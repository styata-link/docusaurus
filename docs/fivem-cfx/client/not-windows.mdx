# Modified Windows

## I am getting this error when loading up FiveM


![](/img/not-windows.png)

Unfortunately the only solution we have for now is to reinstall Windows via the "Reset This PC" program, selecting to "Remove everything" 
and to do a "Cloud download". 
This will delete everything on your computer, so make sure to back up important files, documents & pictures.
