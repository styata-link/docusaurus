# CURL Errors

> If you have an error message that looks like the image below, follow this guide.

![](/img/curl.png)

## What is a CURL Error?

 CURL errors are usually the result of networking issues, either from the server host or with your internet connection. 
 These errors are not caused by the FiveM client or FXServer directly.

You can use the [FiveM Test Server](https://cfx.re/join/y4lg95) to see if its an issue with your client, or the server
you are joining.

## I am still getting the issue on the Test server!

Connections to FiveM services could be blocked by your firewall, or your network (if you are on a corporate or school wifi)
