## My server has been suspended, what do I do?

Typically, server suspensions are caused by violating the [Cfx.re PLA](https://static.cfx.re/platform-license-agreement-12-jan-2026.pdf). 
The only to fix/prevent this from happening again, is to remove the following:

- Any IRL Vehicles
- - [Debadging is NOT enough.](https://forum.cfx.re/t/community-pulse-october-2023-edition/5176467)
- IRL Weapon types
> *More can and will be added later, but these are the most common reasons for servers to be suspended.*


After that, you must wait the duration of your suspension - and it will not be lifted.
