# How to change FiveM Entitlements

This guide is to give/show how to change your DigitalEntitlements, to fix issues like:

- Incorrect Rockstar Account 
- Account does not have a valid license


## Steps to change your DigitalEntitlements

1. Press `Win + R`, enter `%localappdata%\DigitalEntitlements\` and click OK
2. Back up all the files in there, leave them in a separate directory.
3. Delete all the files inside of `DigitalEntitlements`.
4. Run Grand Theft Auto V once through the relevant launcher you used to install the game with.
5. Your FiveM client should now use your new identifiers, provided you actually have separate licenses.
