# Link your Discord

To link Discord with FiveM, you can follow this guide:

1. Download the Discord [Desktop App](https://discord.gg)
2. Open FiveM with Discord running

The following popup should appear in your Discord:

![](https://forum-cfx-re.akamaized.net/original/5X/f/f/9/e/ff9e20b4b9112df1af782797904c143029c47c2c.png)

3. Then, click "Authorize"

:::warning
You must not be running Disord as Administrator, and do not have any use of Vencord, as it can cause problems.
:::
